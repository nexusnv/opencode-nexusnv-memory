# C4 Level 4 (Code) — Implementation Guide

**Status:** proposed. **Sources:** Synthesized Report §4.6; V2 docs `/v2/docs/build/plugins/`, `/v2/docs/plugins/`. **Normative on V2 contracts:** `design-spec-v2-production.md` §§1–5. (Note: `c4-04`/`c4-05` are supplementary interface/data specs sharing this sequence, not separate C4 levels — C4 core is Context → Container → Component → Code.)

## Module layout (planned)

Production package (`src/`) and local drop-in (`.opencode/plugins/memory/`) share one codebase; the drop-in keeps the same modules with `index.ts` as the single entry.

```
src/ (or .opencode/plugins/memory/)
└── index.ts        # Plugin.define({ id: "memory", setup }) — wiring only
    ├── brief.ts     # loadBrief, loadPriors (capped)
    ├── hints.ts     # matchIndex (exact match + once-per-prompt throttle)
    ├── status.ts    # statusLine (rotation notice + review-due nudge)
    ├── capture.ts   # captureFailure, snapshotHandoffIfChanged, ledger helpers
    ├── provenance.ts# classifyProvenance, rememberAsserted (source:user fast path)
    ├── guard.ts     # flagInjection (advisory), untrusted labelling, sanitizeForBrief
    ├── tools.ts     # ctx.tool.transform: memory_recall, memory_apply
    ├── files.ts     # readCapped, writeCapped, budget enforcement, archive routing, write mutex
    ├── redact.ts    # secrets blocklist + <private> stripping
    ├── config.ts    # ≤5 options, defaults, validation (ctx.options)
    └── templates.ts # six-file scaffolds + AGENTS.md protocol block text
```

## Function contracts

- IO channel: `node:fs/promises` server-side only.
- `readCapped(file)`: resolves the path under the fixed `.opencode/memory`, rejects any escape (`..`, absolute, backslash, percent-encoded separators), then requires allowlist membership (`INDEX/activeContext/decisions/architecture/style/issues`) or the handoff pattern `/^handoffs\/(?:archive\/)?[A-Za-z0-9._-]+\.md$/`; returns the file text with a truncation notice (the `memory_recall` tool wraps it via `toolResult(text)`, default `{ content }`); unknown/invalid → error; always strips secrets/`<private>`. Archive paths are recallable on demand, never auto-injected.
- `writeCapped(file, text)`: allowlisted paths only; enforces `indexLines`/`fileLines` on every **plugin** write; redacts; serialized through one per-process mutex (single-flight per content ID + append lock); throws on violation for a capped rule file (never silently truncates a durable file), while `activeContext.md` rotates the oldest Known-Errors block to `handoffs/archive/` at the cap instead. Over-cap **hand-edits** bypass this function and are validated (not overwritten) by `/memory-review`.
- `toolResult(text)`: the single adapter for the tool-executor return envelope (`{ content: text }` by default; G2 proven via `Tool.Result`); every tool return goes through it.
- `memory_apply(candidates)`: the only write channel for approved lines — executor binds `sessionID/agent/source` from its tool context; one `ctx.permission.assert({action:"memory_write",resources:[file],metadata:{line,source},source,save:[]})` per candidate sequentially → `writeCapped` on allow, propagate on first deny (no summary); `candidates:[]` resets without writes; untrusted lines cannot be bulk-approved; requires the shipped `memory_write → ask` rule; resets `<projectID>/curation.pending` → 0 and clears `<projectID>/curation.rotated` on completion.
- `loadBrief()`: async; activeContext slice + newest handoff pointer (≤ 48 lines, incl. max 5 error lines, the fixed slice of `injectBudgetLines`); truncates with notice; redacted. Does **not** contain the INDEX map or the decisions tail. **Known Errors contribute message-derived summary lines only** (max 5) — `sanitizeForBrief()` emits one `source:`-tagged line per error (≤120 chars, newlines collapsed; `<cmd>:` prefix only when `event.input` yields it) and never a captured body. Total auto-inject payload (INDEX attach + brief + status + hint) ≤ `injectBudgetLines` (~80); excludes static root `AGENTS.md` directive (~10) + tool description (~3).
- `loadPriors()`: async; capped + redacted priors for the compaction hook (activeContext slice + decisions tail ≤60 + handoff pointer); truncates with notice. The only auto-inject path for the decisions tail.
- `matchIndex(event)`: async; exact symbol/file match parsed from **`event.messages: Message[]`** (latest user-authored text; the `context` event carries no `prompt.text` but does carry `sessionID`) against INDEX; returns a 1-line hint or `undefined` — never content, never fuzzy; **throttled via `<projectID>/hint/<sessionID>/<promptHash>`** so tool-driven continuations do not re-inject it.
- `statusLine(event)`: **async**; resolves to ≤1 `[memory]` line or `undefined`, from `ctx.storage` counters only (no filesystem listing, redacted). Emits the rotation notice once (from `<projectID>/curation.rotated`, then clears it; one concurrent double-emit tolerated) and the review-due nudge while `<projectID>/curation.pending ≥ 5` (scratchpad only); both facts share one line if they co-occur; dropped before the hint under budget pressure. Thresholds are fixed, not options. The line is model-facing (`event.system`); delivery to the user depends on the agent relaying it.
- `captureFailure(event, ledger)`: failures only (`event.status === "error"`; `Tool.Error{message}` only — G4), redacted, ledger-guarded (`ctx.storage`, content-ID check-before-write, ~30s retry); writes a `source:tool` message-derived summary line plus an **optional** recall-only detail block written only when the event carries output; increments `<projectID>/curation.pending` (scratchpad only) and sets `<projectID>/curation.rotated` on rotation.
- `classifyProvenance(turn, text)`: returns `user | tool | model | snapshot`. `user` only for an explicit `remember:`/`remember that` line-start directive in the user's own turn, outside code fences/quotations (pastes covered only by that heuristic); ambiguous → the non-user class. Pure, testable, no LLM — **detection only**; the write site is the `prompt` hook.
- `rememberAsserted(text, ledger)`: `source:user` fast path — redact, ledger-dedup, append to append-only `decisions.md` tagged `(user-asserted)`, never incrementing pending. Called from the `prompt` hook (the only hook that sees the user's turn before admission); serialized (write mutex) and never-throw (a throwing prompt hook blocks admission). The plugin is the sole writer. Never targets `architecture.md`/`style.md`/`issues.md`.
- `sanitizeForBrief(entry)`: collapses the entry to one message-derived summary line (newlines collapsed, ≤120 chars) with its `source:` tag; the body is dropped, not truncated into the brief.
- `flagInjection(text)`: returns advisory flags (imperative/instruction-shaped text, agent-directed directives, URL/`fetch` payloads, encoded blobs). Never blocks, never rejects, never labelled "detected".
- `snapshotHandoffIfChanged(event, ledger)`: resolves the memory root for the **event's** session/location (`event.location` + `data.sessionID`, fallback `ctx.location`), never a root captured at load, and runs only for events in this location (`isThisLocation` compares directory + session/project IDs); `branch` via `(await ctx.vcs.get()).data.branch.current` (fallback `(await ctx.vcs.branch.list()).data[0] ?? "unknown"`); open changes via `(await ctx.vcs.status()).data` (fallback `(await ctx.vcs.diff({mode:"working"})).data`, normalized since the fallback changes `FileStatus[]` to `FileDiff[]`); hash(branch+status+pending); same hash as `<projectID>/snapshot/<sessionID>` → no-op, else new immutable `handoffs/YYYY-MM-DD-HHmmss-<session6>.md`; newest wins. Async, fire-and-forget, serialized, never-throw per dispatch (a throw on event N must not stop N+1). All VCS calls sit behind one adapter.
- `ledger`: `ctx.storage` only — `<projectID>/seen/<id>` + `<projectID>/attempt/<id>` + `<projectID>/curation.pending` (scratchpad-only) + `<projectID>/curation.rotated` + `<projectID>/snapshot/<sessionID>` + `<projectID>/snapshotThrottle/<sessionID>` + `<projectID>/hint/<sessionID>/<promptHash>`, pruned via `scan({prefix:"<projectID>/seen/"})` with `after`/`next` pagination to ≤500; compaction `ended` replay-guarded via `<projectID>/seen/<event.id>`; persisted, never in-memory alone. The API has no compare-and-set, so a single-flight map keyed by content ID serializes concurrent `execute.after` checks; a duplicate that still slips through is benign.
- Lifecycle: capture each `Registration` returned by `hook`/`transform`; a **single shared** event `AbortController` (not one per subscriber) is aborted and every registration is disposed in the `setup` cleanup, which awaits `dispose()`. Unloading also disposes registrations; async cleanup awaiting is best-effort (G3).

## Setup / dev

- Config location matters. If config is `.opencode/opencode.jsonc`: `"plugins": ["./plugins/memory"]`. If config is repo-root `opencode.jsonc`: `"plugins": ["./.opencode/plugins/memory"]`. Drop-in alternative: `.opencode/plugins/memory/` auto-discovery; `opencode plugin list` verifies load; touch the entry file or restart the runtime per its reload guidance if a stale load is suspected.
- First run scaffolds templates + `handoffs/` and emits the commented ≤5-option snippet; it never edits `opencode.jsonc` or `AGENTS.md` (ADR-0006).
- Pin an exact tested `@opencode/plugin` release (2.0.x; tested `2.0.29`); never `latest`.

## Test list (pre-merge acceptance)

Budget enforcement on every write path (and over-cap INDEX is not attached); ledger idempotency across restart/replay (persisted `ctx.storage`, not in-memory); injection ≤ `injectBudgetLines` with prompt-hook dedup and no INDEX duplication in the brief (decisions tail via priors+recall only); status line — rotation notice emitted once then cleared (one concurrent double-emit tolerated), review-due nudge at ≥5 uncurated scratchpad captures and gone after `memory_apply` reset, dropped before the hint under budget pressure; **injection containment — a fixture whose captured error text carries an agent-directed instruction lands on disk but the brief carries only the message-derived summary line (max 5); `classifyProvenance` rejects instructions inside code fences/quotations (pastes via that heuristic); `flagInjection` never blocks or alters a write; untrusted candidates are excluded from bulk approval**; **provenance gate — documented user directive appends to `decisions.md` immediately and tagged without pending increment, ambiguous/tool-origin `remember` does not**; compaction injects priors (activeContext+decisions tail+handoff) and **never sets `event.result`** and uses no custom trigger; `compaction.ended` text+recent captured; nested-`AGENTS.md` caveat covered (memory outside nested files); redaction blocks secrets fixtures and `<private>` (incl. unclosed tags); `memory_recall` rejects unknown/traversal paths and returns the executor envelope via `toolResult` (default `{ content }`, asserted against the installed package — G2 proven); `memory_apply` approves one candidate line per `ctx.permission.assert` and resets pending/marker; `handoffs/` root vs `handoffs/archive/` routing covered; branch via `vcs.get()`, changes via `vcs.status()`; `scan` uses `<projectID>/seen/` prefix with pagination; `memory-manager` denies `*` then allows only `read/glob/grep`, and the `subagent` allow for it is present when the optional delegation path is enabled; there is no session permission lock (retired G5); every hook touching storage/vcs is async and never throws; foreign-location events (`event.location`) are dropped before any write; the single event `AbortController` is reused and cleanup awaits `Registration.dispose()` (async await best-effort, G3). **P1 gates (design-spec §1.3, type-proven):** deploy-time `event.type` log confirms `session.idle` / `compaction.ended` delivery; G2/G4 proven via types. G5 is retired.
